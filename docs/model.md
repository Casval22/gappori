# 数理モデル

## 厳密な抽選

通常列と特殊を含む h、N=Σh とする。5球の集約個数ベクトルxを列挙し、重みを

`P(x) = Π C(h_i, x_i) / C(N, 5)`

とする。物理ポケット集合の数え上げに等価で、個数ベクトル一様ではない。成立条件は通常列全てで x_i >= r_i。要求しない列・特殊も分母に含む。

h=[1,2,3,4,5,1]では C(16,5)=4368。

| 要求             | 成立集合数 |       成立確率 |
| ---------------- | ---------: | -------------: |
| 舟 [0,1,1,1,2]   |        240 |  5.4945054945% |
| 下駄 [0,0,1,1,1] |       2030 | 46.4743589744% |
| 舟 [0,0,0,0,5]   |          1 |  0.0228937729% |

FCなしの払出は各共通状態ごとに全員・全行の総払出を合算し、純増=総払出−総費用の分布を集約する。同じ要求の皿数は成立確率を増やさない。グループを独立確率で合成しない。

## FC

前半y・後半zの重みは `ΠC(h_i,y_i)/C(N,3) × ΠC(h_i−y_i,z_i)/C(N−3,2)`。

`chooseFc`の入力はh、要求、前半y、ルールだけ。各選択可能列について後半の全状態を列挙し、その条件付き成立確率を比較する。実際に起きたzは引数に渡せない。最良列は前半ごとに固定し、その後に後半結果を評価する。

行獲得率は行単位ならp、皿ごと独立なら `1−(1−p)^n`。不明時は当該行のFCを除外しラベルを付ける。

共通(y,z)に条件づけると、FC獲得の仮説上は行の成立が独立になる。行の成立確率をt_jとすると個人の何か成立は `1−Π(1−t_j)`。この個人確率から条件付きの誰か/全員を計算し、最後に共通(y,z)を積分する。したがって個人・グループ成立確率と期待払出は厳密。

FCありの収支分布は共有物理状態をサンプルし、各行のFC獲得を独立サンプルする12,000試行のseed付き推定。確率の95%誤差の目安は最大分散で `1.96×0.5/√n`（約±0.89ポイント）。期待払出はサンプル平均ではなく厳密値を使う。「全員が次回も購入可能」は各共通状態で1人最大3行の払出分岐を列挙し、各人の生存確率を条件付きで合成した厳密値。

## 探索と評価

要求ベクトルを列数に応じて全生成する。FCなしでは物理的に不可能な要求を除外する。FCありでは「1列を補えば成立可能」という上界で候補を残す。

候補のうち今回配当あり最大16行、基準確率上位12行、FC上界上位10行、列別の集中要求などを重複除去して最大36行保持。丸皿は登録済み分のみ。上限到達は探索の枝刈りであり、最適性の保証ではない。

各人について数量は単位、2単位、5単位、予算内最大単位数、数量指定配当の数量を探索。全数量は列挙しない。単独上位から幅8のビーム探索、拡張候補最大24、行数最大3。異なる要求の個人最終候補3案までを残す。最大4人なら共同候補最大3^4=81を共通抽選で比較し、3案まで表示する。

今回の配当がある購入可能な単独候補が存在する場合、全行配当既知の候補内だけで収支最適化する。配当なしのときは期待収支を0と表示せず、収支項を無効化し確率ベースと表示する。

個人評価は以下の加重和。全体スタイルの重みと個人プリセットの重みを平均する。カスタム重みは設定で変更できる。

- 頻度 F：何か成立する確率。
- 期待純増 R：既知配当の期待純増を費用で割り、tanhで−1〜1に正規化。
- ハラハラ T：前半3球の条件付き成立確率qに対する `E[4q(1−q)]`、BET行平均。
- 大当たり J：検索時は「その行の払出−全費用が閾値以上」の行確率和を1で切った代理値。表示時は合算純増分布から正確/推定の閾値到達確率を再計算。検索の上界と表示の確率は区別する。
- 費用 E：`1−費用/min(残高,予算)`。
- 操作 O：`min(1,推定秒数/(設定上限または30秒))`。

`score = wF×F + wR×R + wT×T + wJ×J + wE×E − wO×O`

| スタイル     | 頻度 | 期待純増 | ハラハラ | 大当たり | グループ | 操作 | 費用 |
| ------------ | ---: | -------: | -------: | -------: | -------: | ---: | ---: |
| 長持ち       |  0.7 |        1 |      0.1 |      0.1 |      0.1 |  0.3 |    1 |
| バランス     |    1 |      0.6 |      0.3 |      0.3 |      0.4 |  0.2 |  0.3 |
| 一撃重視     | 0.25 |      0.3 |      0.5 |      1.8 |      0.1 |  0.1 |  0.1 |
| グループ重視 |  0.5 |      0.4 |      0.2 |      0.2 |        2 |  0.2 |  0.3 |

グループ評価は個人score平均＋グループ重み×目標確率。目標は誰か成立、全員成立、全員が次回の同じBETを買える確率。最後の項が配当不足で計算不能なら全員成立を代理にして警告する。長期持続シミュレーション自体は探索の目的関数ではなく、採用案の別評価。

操作数は各行ごとに皿種選択1＋要求する列の種類数＋数量が単位より多ければ数量変更1。実機の実測時間ではない。指示は列番号順に提示し、各要求個数と皿数を別表示する。

ハラハラ・長持ち・大当たりの重みは説明可能な代理指標であり心理学的効用ではない。ヒューリスティック探索は大域最適解ではない。

## 持続性

`M_next = M − actualCost + grossPayout`。現在の型・ルール・BET・配当を固定して反復し、全員に同じ物理5球、FCだけ行ごとの独立獲得を適用する。購入できない人は停止し復帰しない。数量は固定。

H回を上限とする平均回数・中央値、K回以上の確率、K回未満の終了確率、H到達の打切り件数を算出。生存確率にWilsonの95%信頼区間を添える。最初の人の停止と最後の人の停止を分ける。入力秒数がある場合だけ平均の分換算を行う。配当不明または購入BETなしの参加者がいる場合は実行しない。
